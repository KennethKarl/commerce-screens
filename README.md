# 모바일 커머스 화면 목록

국내외 쇼핑몰과 쇼핑몰 솔루션, 국내 법령, 앱스토어 정책을 조사해 정리한 모바일 커머스 화면 목록입니다.

**https://kennethkarl.github.io/commerce-screens/**

## 구성

- `index.html` — 페이지 전부입니다. 빌드 도구 없는 단일 파일이고, 화면 데이터는 파일 안 `<script id="data">`의 JSON에 들어 있습니다. GitHub Pages가 그대로 서빙합니다.

## 고칠 때

- 공개 저장소입니다. 회사명과 사내 정보를 파일에 쓰지 마십시오.
- 검색 엔진 수집을 막는 `noindex` 태그를 유지합니다.
